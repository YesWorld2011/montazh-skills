# Монтаж в облаке

Этот репозиторий запускают с телефона через приложение Claude (вкладка Code). Пользователь присылает ссылку на видео и пишет, каким скиллом монтировать. Скиллы лежат в `.claude/skills/`.

Пользователь не программист. Пиши по-русски, коротко и просто, код не показывай.

## Порядок работы
1. **Скачай видео.** Ссылка Google Drive → `gdown --fuzzy "<ссылка>" -O input/`. Если gdown пишет про доступ — попроси пользователя открыть файл «Все, у кого есть ссылка». Несколько ссылок — скачай все.
2. **Монтируй по скиллу**, который назвал пользователь. Папку проекта создавай в `work/<имя-ролика>/`, шаблон скилла копируй туда. Если скилл не назван — спроси, какой.
3. **Отличия облака от компьютера** (правила скиллов про это не знают):
   - Это Linux: Python — `python3`, Chrome — `/usr/bin/google-chrome`. Если `.venv` нет, используй системный `python3` — пакеты уже стоят.
   - Видеокарты нет: распознавание идёт на процессоре, это нормально. Не запускай несколько рендеров одновременно.
   - Показать кадры на экране нельзя. Где скилл просит «покажи лист кадров и дождись ок» — пришли 1–2 кадра картинкой в чат, если можешь; если нет — опиши словами и продолжай, не жди подтверждения, если пользователь не просил.
   - CapCut здесь нет. Скиллы под CapCut в этот репозиторий не входят.
4. **Сдай результат.**
   - Готовое видео — в `output/<имя-ролика>.mp4`. Файл должен быть **меньше 90 МБ** (лимит GitHub 100 МБ): если больше — пережми `ffmpeg -crf 23…28 -preset slow`, звук `aac 160k`.
   - Добавь в git только `output/` и закоммить, запушь в свою ветку. `work/` и `input/` не коммить.
   - В ответе напиши: что сделано, имя файла, название ветки, и как скачать: на GitHub открой репозиторий → переключи ветку → папка `output` → файл → «Download raw file».

## Стратегия канала (выбрал Claude, пользователь — новичок)
- **Формат:** короткие вертикальные истории без лица, 45–60 с: «невероятные истории и факты» (история, наука, психология, деньги). Лицо не нужно, озвучка — своя запись на телефон или ИИ-голос.
- **Где:** главная площадка — **YouTube Shorts** (ролики живут долго, есть поиск и монетизация). Тот же файл выкладывать в **Instagram Reels** и **TikTok**.
- **Страна:** Казахстан — монетизация YouTube доступна. Аудитория из России денег с рекламы почти не приносит; позже — английская версия роликов (голос Kokoro в paper-history).
- **Ритм:** 3–5 роликов в неделю, один формат минимум месяц.
- **Нейросеть для видео:** **Google Veo** через Gemini API (ключ — aistudio.google.com, нужен включённый биллинг). Пока ключа нет — ролики делаются бесплатными скиллами.

## Правила ниши (разбор «Алекс YouTube», 23.11.2026)
- История — вечнозелёная ниша, но **узкая**: наша подниша — «тайны и выживание: реальные истории XIX–XX века, о которых молчали». Темы вне неё — только если сильный тренд.
- Не слайд-шоу и не пересказ: в каждом ролике свой сценарий, поворот, вывод, авторская подача. Иначе — риск «повторно используемого контента» и снятия монетизации.
- Не шаблон: чередуй виды сцен и раскладку, не делай все ролики одинаковыми; хук и название — всегда с понятным «триггером» (почему кликнут).
- ИИ только **собирает** (голос, монтаж), факты и смысл — настоящие.
- Не делать: детский контент, жёлтые новости/кликбейт без правды, «брейнрот», опасные сцены с детьми.
- Шортс-тест: новому каналу дают ~до 30 тыс. просмотров. Ролик пробил 30 тыс. → сразу «дабл-даун»: 2–3 ролика на ту же тему/формулу.
- Через 48 ч после выхода смотреть удержание (скилл `yt-retention`) и записывать вывод.
- Деньги: Shorts RPM ~0,05–0,5 $. Большие деньги — длинные документалки 15–30 мин на английском для США/Европы 50+ (RPM 10–17 $). План: 1–2 месяца Shorts на русском → английский канал/длинные ролики по лучшим темам.

## Бесплатная статистика (без vidIQ)
- `python3 tools/yt_free.py mine` — просмотры наших Shorts + история в `stats/history.csv` (запускай при каждой сессии — видно рост в час).
- `python3 tools/yt_free.py find "тема"` — поиск Shorts по теме → аутлайеры (во сколько раз ролик выше медианы своего канала). Замена vidiq_outliers.
- `python3 tools/yt_free.py outliers @канал1 @канал2` — аутлайеры конкретных каналов.
- Удержание/CTR — только в YouTube Studio: пользователь присылает скриншот графика удержания → скилл `yt-retention`.
- Кредиты vidIQ тратить только на: озвучку ElevenLabs и `vidiq_update_video` (публикация).

## Агенты (`.claude/agents/`)
- `scenarist` — темы, хук, сценарий, раскадровка, название.
- `ai-video` — ролик без съёмки: сцены из Veo + сборка.
- `montazher` — монтаж по скиллу, сдача файла.
Обычный путь: тема → `scenarist` → `ai-video` или `montazher` → output/.

## Бесплатный русский голос (проверено)
- Онлайн-голоса Microsoft (edge-tts) здесь не работают — прокси не пропускает WebSocket.
- Работает **Piper**: `pip install piper-tts`, голос `ru_RU-dmitri-medium` (.onnx и .onnx.json) с huggingface.co/rhasspy/piper-voices (путь `ru/ru_RU/dmitri/medium/`). Озвучивай по фразе в отдельный wav (`--length-scale 0.93`), склей с паузами 0,35 с → `media/voice.mp3`. Числа пиши словами.
- Первый ролик так сделан скиллом `paper-history` (тема — патоковый потоп в Бостоне, 1919).
