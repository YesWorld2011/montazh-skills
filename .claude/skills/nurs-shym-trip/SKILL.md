# НУРС-SHYM-TRIP

> Скилл из обучения **Нұрсерік** — курс **PROXIMA «Монтаж с Claude»**. Собран на ролике «Ержан / wipe transition» (16–19.11.2026): каждое правило ниже — реальная правка Нұрсерік, полный список — в `ОШИБКИ_И_ПРАВКИ.md`.
> Нұрсеріктің оқуындағы скилл: Нұрсерік бұл рилсті дәл осылай монтаждады.

Пользователь — не программист: объясняй просто, код не показывай без просьбы. После каждого этапа — «что сделал / что проверить» и кадр-проверка. Отвечай на языке пользователя (казахский/русский вперемешку — нормально).

## Что внутри
- `template/` — движок (`engine.js`, `style.css`), рендер (`render.mjs`), звук (`remix.mjs`), шрифты и звуки (`a/`), вырезка спикера (`scripts/mask.py`, `models/`), распознавание (`scripts/words.py`).
- `template/examples/ержан-финал.html` — принятый финал (v10). `ержан-до-после.html` — принятый ДО/ПОСЛЕ.
- `scripts-шаги-ержан/` — скрипты каждого шага на реальном проекте (бери как образец и меняй цифры).
- `ОШИБКИ_И_ПРАВКИ.md` — все правки по порядку и мои ошибки. **Прочитай перед началом.**

## Порядок работы
### 1. Нарезка в CapCut (покраску НЕ трогать)
1. Найди проект: `%LOCALAPPDATA%\CapCut\User Data\Projects\com.lveditor.draft\*\draft_meta_info.json` → `draft_name`. Папка может называться иначе (1116 → «ержан»).
2. Источник и LUT-ы — в `draft_content.json` (`materials.videos[].path`, `materials.effects` type=lut). **Покраску не менять** — только резать дорожку.
3. Распознавание длинного исходника: `scripts-шаги-ержан/words_long.py` (kk, VAD) — **VAD пропускает дубли**. Обязательно досканируй без VAD кусками по 12 с (`gaps.py`) — в Ержане так нашлись более поздние дубли трёх фраз.
4. По каждой фразе сценария — **самый последний дубль**. Границы — по энергии звука (`cuts.py`), проверка каждого куска распознаванием (`verify.py`): нет фальстартов, шорохов, слова целые.
5. Запись в проект: `to_capcut.py` (каждому куску — свои копии speeds/canvases/…; adjust-слои с LUT растянуть на новую длину). **CapCut должен быть закрыт.** Сначала бэкап проекта.
6. Пользователь экспортирует 1080×1920 → это исходник для графики (покраска сохраняется 1:1).

### 2. Подготовка
`ffmpeg -i ИСХОДНИК -vf fps=30 -q:v 3 media/frames/%05d.jpg`, голос → `media/voice.m4a`, `python scripts/mask.py`, `python -I scripts/words.py media/source.mp4 kk > media/words.json`. Замерь верх головы по маскам (`data-ty="80"`).

### 3. Стиль (принятый)
- **Жёлтый узкий капс** Druk Cond Super `#FFE81A` (`.yb`), слева или по центру, крупно; **белая рукописная** KZ Toms (`.hw`) над ним и под ним — продолжение фразы. Нижних субтитров **нет**.
- **Все слова — по одному, плавно снизу вверх**: `data-fx="words" data-wdur="0.6" data-wdy="48" data-wblur="16"`.
- **Хук**: две строки одинаковой ширины (`data-fitw`), небольшие, низ второй строки чуть уходит за голову (`bh`).
- **За головой** (`bh`): верх букв над головой, нижняя ~треть за головой, всё читается. Так — WIPE TRANSITION, ПЕРЕХОД, LET'S GO.
- Строка над словом той же ширины — `data-fitto="id"` (ставится вплотную сверху).
- **Склейки жёсткие**: `data-tr="none"`, `data-intro="none"`, **`data-push="0"` на сценах спикера** (иначе на склейках одного и того же кадра масштаб прыгает).
- Не делать: плашки-теги, иконки-часы, рамки вокруг карточек, неон, мультяшные пружины, поисковое поле/курсор в финале, чёрный фон в финале.

### 4. Структура рилса (как в Ержане)
1. Хук на спикере.
2. **Демонстрация приёма** — B-roll только со **своим** звуком, голоса нет (в мастер вставляется окно тишины, `build_master4.py`); на стыке — тихий кинематографичный вжух, звук примера плавно затихает.
3. Спикер «бұл WIPE TRANSITION деп аталады» — без паузы перед первым словом.
4. Примеры из чужого ролика пользователя — **под те же слова, где они стоят у него** (`cut_examples.ps1`: найти склейки `select=gt(scene,0.25)`, вырезать, подогнать скорость под длину фразы). Горизонтальные — в скруглённой карточке на тёмном фоне с размытой подложкой; вертикальные — на весь кадр.
5. Блокнот TRAVEL/FASHION/COMMERCIAL — настоящий B-roll, куски выровнены по словам.
6. «Охват» — 5 превью рилсов (2 сверху, 3 снизу), скруглённые, без рамок, появляются плавно по одному и чуть-чуть плывут вперёд.
7. «Қолмен» — B-roll съёмки руками, «бірақ көп уақытың кетеді» — сразу после.
8. Финал на спикере: «комментке / ПЕРЕХОД (за головой) / деп жаз», над ПЕРЕХОД вплотную «мен саған дайын вариантын жіберемін» той же ширины. LET'S GO за головой.

### 5. Мастер (если надо убрать паузы / вставить окно / дотянуть слово)
Не перерезать в CapCut — пересобери кадры+маски+голос (`build_master*.py`): выкинуть кадры паузы, вставить окно, дотянуть хвост из исходника **теми же LUT пользователя** (`lut3d`, подгонка среднего/контраста к последнему кадру экспорта). После каждого изменения — распознай голос заново и сдвинь сцены.

### 6. Звук (`remix.mjs`, переменные окружения)
- Голос + еле слышные кранчи/клики на каждое слово и карточку (`a/sfx_pro`, ~22–26 дБ тише голоса), в сцене-вставке ещё тише: `QUIET="a-b" QK=0.4`.
- Звук демонстрации: `WIPESET=<сек> WVOL=0.72`. Вжух на стыке: `CUTWHOOSH=<сек> CWVOL=0.13`.
- Музыка: `MUSIC`, `MUSIC2`, `MSS`/`MSS2` (откуда брать трек), `XF` (где плавно перетекает, 1.2 с), `MVOL=0.2 MVOL2=0.17`, паузы `DROPS="a-b,c-d"` (на «бірақ», перед «let's go»). Под голос — sidechain.
- Звуки переходов на каждую склейку (cin) — **нет**.

### 7. Рендер в высоком качестве
`$env:JPGQ="97"; $env:CRF="15"; $env:PRESET="slow"; node render.mjs full`, затем `node remix.mjs video.html out\video.mp4 "итог.mp4"` (видео копируется, **второго сжатия нет**). Итог ~9 Мбит/с, yuv420p tv.

### 8. ДО / ПОСЛЕ (`examples/ержан-до-после.html`)
Только метки ДЕЙІН и КЕЙІН (никаких заголовков и CTA). Звук — из готового. **ДЕЙІН берётся из мастер-кадров (сырой материал, выровненный по таймлайну финала)**, а не из исходного файла — иначе губы не совпадают. На окно демонстрации — затемнение и подпись «wipe transition b-roll».

## Чек-лист
- [ ] Покраска не тронута; в CapCut — только резка, бэкап сделан.
- [ ] Последние дубли, слова целые, пауз и пустых склеек нет.
- [ ] Хук: две строки одной ширины; «за головой» читается.
- [ ] На спикере `data-push="0"`, склейки не прыгают.
- [ ] Демонстрация — без голоса, со своим звуком; вжух тихий.
- [ ] Музыка тише голоса, переход треков плавный, паузы на месте.
- [ ] Одно сжатие, CRF 15; ДО/ПОСЛЕ синхронен.
