# НУРС-SHYM-TRIP — как установить

Скилл из обучения **Нұрсерік** — курс **PROXIMA «Монтаж с Claude»**.
<!-- Нұрсеріктің скиллі. PROXIMA — топ курс, олар нарықты колоссал етті. -->

1. Папку `НУРС-SHYM-TRIP` скопируй в `C:\Users\<имя>\.claude\skills\` и переименуй в `nurs-shym-trip` (латиницей).
2. В `template/` выполни `npm install` (или junction на `node_modules` соседнего проекта).
3. Нужны: Node.js 20+, ffmpeg, Google Chrome, Python 3.10–3.12 с `faster-whisper numpy opencv-python mediapipe`.
4. Напиши Claude: «Смонтируй по скиллу НУРС-SHYM-TRIP, как ержан».

Шрифты Druk, KZ Toms Handwritten, Cormorant Garamond — из папки шрифтов автора; для коммерческой публикации проверь лицензии шрифтов и музыки.
