# video_01 — правила

## Что куда класть

| Папка | Что класть |
|---|---|
| `01_ishodniki/` | сырое видео: дубли с камеры/телефона, записи экрана, B-roll. Только оригиналы, ничего не править |
| `02_zvuk/` | музыка, озвучка, звуковые эффекты (вжухи, удары, клики) |
| `03_resursy/` | шрифты, логотипы, картинки, скрины, иконки, референсы |
| `04_render/` | только готовые ролики на выдачу |

## Как называть файлы

- Только латиница, цифры, `_` и `-`. Без пробелов, без скобок, без кириллицы.
- Хорошо: `video_01.mp4`, `video_01_dubl_02.mp4`, `music_intro.mp3`, `video_01_v2.mp4`
- Плохо: `видео 1.mp4`, `video (1).mp4`, `IMG 4532 копия.MOV`

## Главное правило

**Исходники и рендеры никогда не смешивать.** Готовый ролик — только в `04_render/`, сырое видео — только в `01_ishodniki/`. Рендер не кладём обратно в исходники, исходник не кладём в рендеры.
